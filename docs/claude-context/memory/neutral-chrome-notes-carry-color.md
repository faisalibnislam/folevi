Inside the product, the interface chrome is neutral: light mode fully white (not greyish), dark mode black/near-black. Colour comes only from the notes themselves (covers, artwork, accent colours). Marketing site keeps the warm palette.

**Why:** Owner asked (2026-09-26) for "neutral color, black and dark" with notes carrying their own colour, and explicitly "white mode background will be fully white, not greyish". Reference screenshots were Craft's Mac app.

**How to apply:** Don't reintroduce warm/tinted backgrounds or glows in app chrome. Page layout follows Craft: tab strip with Home tab + one tab per open page; on pages the left sidebar shows page tools (contents/tasks/attachments/find) by default, with a "Show folders" option; inspector text tabs Insert/Format/Style/Info; Home grid shows portrait page thumbnails. See [[mac-follows-web]] — the Mac app should adopt this when it's updated.
