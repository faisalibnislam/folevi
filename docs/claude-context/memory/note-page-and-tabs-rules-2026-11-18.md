Decided by the owner on 2026-11-18 (after Craft screenshots), shipped in Folevi 1.4.46 for web and Mac:
- Plain note (no style backdrop): one flat page, no card, corners or shadow; text keeps its centered column.
- Plain note with page breaks: each page a white card on a light grey backdrop, very soft shadow. Styled notes keep their backdrop with the page card, same lighter shadow.
- Padding round the page follows the window width smoothly (Craft-like), no breakpoint jumps.
- Mac title bar tabs: Safari's rule, every tab the same width filling the bar; open tab same width; x on the open tab and on hover.
- Mac note layout = web's: left sidebar shows the note's tools (contents, comments, tasks, attachments, find) with a Folders switch beside the sidebar button; Style/Format/Insert/Foli AI on the right. Account stays at the top of the sidebar.
- Show All Tabs should look like Safari's (real pictures of each tab).

**Why:** the owner found the old look inconsistent (content-hugging tabs, boxed plain notes, dead Note Tools button).

**How to apply:** iPhone and iPad get the flat note / page card rules in a later pass (owner said "later"); keep new Mac/web UI consistent with these. Related: [[mac-polish-rules-2026-11-18]], [[mac-native-look-decisions]].
