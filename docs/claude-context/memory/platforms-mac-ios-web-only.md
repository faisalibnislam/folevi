Native apps: Folevi for Mac (apps/desktop, [[mac-is-electron]]), Folevi for iPhone and iPad (apps/ios, [[ios-app]]) and, planned since 2026-10-22, Folevi for Android (apps/android, [[android-app]]). On 2026-10-16 the user said "Drop windows app" and "drop the android app too"; on 2026-10-22 they asked for the Android app again ("I'm also a full android developer").

**Why:** Apple platforms plus the web first; Android is back because the owner can maintain it.

**How to apply:** don't build, plan or propose a Windows app unless asked. Android follows [[android-app]]. The web app keeps working in Android browsers (PWA) either way.
