# Home: customizable dashboard with greeting, capture bar, Scratch pad, Today and My tasks

- Date: 2026-11-28 03:49 UTC
- Area: web
- Branch: claude/dazzling-sanderson-1d2975

The owner combined three concepts from the Home concepts canvas into one design (https://claude.ai/artifact/4kYxTQcFRtsvwXydbTXc84, Main.dc.html, 28 November 2026): the widget grid (concept 1), the calm start's greeting and capture field (concept 4), and the briefing's Up next and Recent notes (concept 5), plus Foli DNA and Recent folders.

- Top: Customize at the right; the date and "Good morning, <first name>" centred; a capture field ("What's on your mind?") with "Saves to" (a picker of Drafts and the folders of every space the person is in, Personal and workspaces, remembered on this device in localStorage) and Add as a task, Start from a template and Save. Save makes a note through imports.importText (first line the title, the rest the body, as the Mac's "New note with text"); Cmd/Ctrl+Return saves too. The concept's Voice and Screenshot tools have no web feature behind them yet, so they're left out. The Foli AI Catch me up and Today's reviews stay under the field, unchanged.
- Blocks, in a three-column grid (one column under 760 px): Scratch pad + Recent notes (three real note cards, span 2); Up next (today's events still to come and open tasks due today or overdue, in time order: lib/app/homeLayout.ts upNext), Today (the day's calendar events, externalCalendars.events), My tasks (open tasks soonest due, tick to complete with the Tasks page's useToggleTask); Foli DNA (this week's most linked note in the middle with its linked notes around it in their folder colours, from aiGraph.graph; a week without new links shows the most linked notes of all); Recent folders (one row of the real folder cards). Bookmarks is a block too, off until added.
- Customize: dashed blocks with move earlier / later and take-off-Home buttons; an Add a block tile with the blocks not on Home; Reset to the default Home. Saved per person.
- Backend: table homePrefs (profileId, order, hidden, scratch) and convex/homePrefs.ts (get, setLayout, setScratch), deleted with the account (maintenance.ts); local mode has the same in apps/web/src/lib/local/functions/homePrefs.ts (library meta). Tests: tests/convex/home-prefs.test.ts, apps/web/test/home-layout.test.ts (layout merge, moves, hiding, Up next order).
- Dev Convex (peaceful-mockingbird-196) was pushed from this branch with convex dev --once; the push rebuilt documents.search_text to this branch's (main's) definition, which another branch had changed on dev.
- Checked on http://app.localhost:3044 (this worktree, dev Convex, signed in) at 1440 px and at a narrow pane: real recent notes, overdue tasks in Up next, an empty calendar, the Foli DNA map from the one link in the dev data, real folder cards; hiding a block saved and survived a reload; the scratch pad synced across a reload; Customize's Add a block listed Bookmarks. The layout was reset and the scratch pad cleared afterwards. Save and Add as a task were not clicked (they would make real notes and tasks).
